## Работа с программой WinMark

В общем случае работа с приложением WinMark состоит из последовательности следующих шагов. В зависимости от цели работы некоторые из них могут не выполняться.

1.  #### [Шаг 0. (необязательный). Ввод данных о пользователе](#step0)

2.  #### [Шаг 1. Работа с элементами матрицы](#step1)

3.  #### [Шаг 2. Работа с матрицей](#step2)

4.  #### [Шаг 3. Расчет и вывод вероятностей](#step3)

5.  #### [Шаг 4. Работа с характеристиками](#step4)

6.  #### [Шаг 5. Варьирование элементов](#step5)

7.  #### [Шаг 6. Сохранение графиков, файла данных, формирование отчета](#step6)

### 



## Шаг 0. (необязательный). Ввод данных о пользователе<a id="step0"></a>

- Вызов [диалога ввода данных](windows.md#datadlg) и заполнение его форм.

### 

## Шаг 1. Работа с элементами матрицы<a id="step1"></a>

- [Задание числа элементов и размера матрицы](windows.md#datadlg)(число элементов - от 0 до 2000, размер матрицы от 2 (2х2) до 2000 (2000х200)).Рекомендуется не вводить больших значений.
- [Ввод элементов](windows.md#itemswnd) (пар имя-значение). Имя содержит символы латинского алфавита и цифры, значение - неотрицательное число с плавающей запятой (точность - не более 4-х знаков после запятой).

### 

## Шаг 2. Работа с матрицей<a id="step2"></a>

- [Ввод матрицы](windows.md#matrixwnd). Ни в какой из строк матрицы не могут содержаться только нулевые элементы.
- Сохранение матрицы через меню.

### 

## Шаг 3. Расчет и вывод вероятностей<a id="step3"></a>

- [Расчет вероятностей](menus.md#calcprob) и [просмотр их значений](windows.md#viewprob) (в случае ошибок выводятся соответствующие сообщения).

### 

## Шаг 4. Работа с характеристиками<a id="step4"></a>

- [Ввод числа формул](windows.md#formdlg) (от 1 до 2000).
- [Ввод формул расчета характеристик](windows.md#formwnd)(правильность ввода не проверяется).
- [Расчет характеристик](menus.md#calcform) и [просмотр их значений](windows.md#viewchar).
- [Сохранение](menus.md#save) файла данных (необязательно).

### 

## Шаг 5. Варьирование элементов<a id="step5"></a>

- [Выбор варьируемых элементов](windows.md#varwnd) (задается начальное значение и шаг). Шаг равен 0, если элемент варьировать не нужно.
- [Проведение варьирования](menus.md#calcvar) и [просмотр значений вероятностей и характеристик в точках расчета](windows.md#varprobwnd).
- [Добавление графиков характеристик](windows.md#addgraphdlg) и [их просмотр](windows.md#graphwnd) . Возможно, [изменение свойств осей координат](windows.md#axisdlg).

### 

## Шаг 6. Сохранение графиков, файла данных, формирование отчета.<a id="step6"></a>

- Сохранение графиков через меню [окна графиков характеристик](windows.md#graphwnd).
- [Сохранение файла данных WinMark](menus.md#save) на диске.
- Формирование [отчета о проделанной работе](windows.md#reportdlg).
